### Dynamic deficit feedback is a reparameterization  ·  `CLOSED_ROUTE`

The loop Delta_N -> m_N -> d_N = v_2(3m_N+1) -> Delta_{N+1} is the Bernstein-Lagarias 2-adic conjugacy in deficit coordinates; every arrow is a definition or an already-proved identity. The state-size ceiling d_N <= log2(3m_N+1) is strictly WEAKER than the zero-corridor ceiling d_N <= Delta_N + b for every seed m_0 >= 2, so a large state constrains the next valuation less than the corridor already does.
