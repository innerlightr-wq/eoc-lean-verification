## 1. No irrational barrier — quadratic or otherwise — periodizes the 3-adic exponent

**Theorem (PROVED (MATH)).**  Let `β` be irrational and `M ≥ 2` an integer.  Then `j ↦ ⌊jβ⌋ mod M`
is **not** eventually periodic.

*Proof.*  Suppose `⌊(j+T)β⌋ ≡ ⌊jβ⌋ (mod M)` for all `j ≥ j₀` with `T ≥ 1`.  Since `Tβ ∉ ℤ`,
`⌊(j+T)β⌋ − ⌊jβ⌋ = ⌊Tβ⌋ + [ {jβ} + {Tβ} ≥ 1 ]`, so the increment takes exactly the two values
`⌊Tβ⌋` and `⌊Tβ⌋+1`, each for infinitely many `j` (the fractional parts `{jβ}` are dense, and
`{Tβ} ∈ (0,1)`).  Both would have to be `≡ 0 (mod M)`, impossible for `M ≥ 2` since they differ
by 1. ∎

**Consequence (Part XXIX).**  `2^{−⌊jβ⌋} mod 3^q` is not eventually periodic in `j`, because its
period would force periodicity of `⌊jβ⌋` modulo `ord(2 mod 3^q) = 2·3^{q−1} ≥ 2`.  **Quadratic
irrationality provides no simplification whatsoever of the 3-adic exponent.**  This holds for every
`β` in the round's families and is not a numerical observation but a proof.

## 2. The real structure: a compact fiber driven by an uncontrolled digit input

The earlier framing — "blackness at block `r` needs modulus `3^{2r+2}`, which grows" — is about the
*representation*, not the state.  The exact structure is:

Let `θ_b(x) = centered(ξ·2^{x−m} mod 3^b)/3^b ∈ [−1/2, 1/2)`; Tao-blackness is `|θ| < η = 1/54`.
**Verified exactly in-session (648/648 transitions, no violations):**

  **`θ_{b+1} = (2^d·θ_b + j)/3`,  `j ∈ ℤ`, `|j| ≤ 2^d`**

where `d` is the step in the column index (a digit of the valuation word, constrained by the
barrier) and `j` is the next balanced-ternary digit of `ξ`.

So:

* the **fiber is compact and one-dimensional** — the interval `[−1/2,1/2)`, not a growing ring;
* the **base** contributes `d` (the word/barrier symbol), which a quadratic `β` renders Sturmian
  and substitutive;
* the **input** `j` is a fresh integer digit of `ξ` at every step, of size `O(2^d)` — i.e. the same
  order as the whole state.

**This is the precise blocker.**  What is uncontrolled is not the state space but the *input digit
sequence*, and that sequence is determined by `ξ = λ2^{−m}`, not by the barrier.  A quadratic
surrogate changes only the `d`-sequence.  Hence (Parts XX–XXII): bounded-discrepancy/balance
properties of the barrier word cannot control blackness, because `θ` receives an order-one additive
perturbation `j` at every single step regardless of the `d`-word.

## 3. Why renormalization does not gain (Parts XXIII–XXVI)

Composing the fiber map over a superblock of `K` levels with total column shift `D = Σd` gives

  **`θ ↦ (2^D·θ + J)/3^K`,  `J = Σ_i j_i·2^{(partial shifts)}·3^{K−1−i} ∈ ℤ`.**

The *form* is preserved (Part XXV's hoped-for affine action exists), but `J` ranges over `~3^K`
values as the `K` fresh digits vary.  **Renormalization therefore aggregates the input entropy
rather than reducing it**: a superblock is an IFS with `3^K` branches, not a single affine map.  So
a substitution-based superblock contraction argument has no fewer degrees of freedom than the
blockwise one.

## 4. Skew-product formulation (Parts XXXVI–XXXIX)

The system *is* a skew product with compact fiber,
`(x, θ) ↦ (x + β, (2^{d(x)}θ + j)/3)`, **but only if the digit `j` is supplied externally**.  For
`j` to be generated by the base one would need the ternary digits of `ξ` to be a function of the
barrier phase — they are not: `ξ = λ2^{−m}` is fixed by the arithmetic of `λ` and `m`, independent
of `α` or `β`.  Therefore:

* the base rotation is uniquely ergodic (Part XXI) — **but that controls only the `d`-word**;
* the cocycle is driven by an exogenous sequence, so no unique-ergodicity or balance statement about
  the base transfers to the fiber (Part XXXVIII: the 3-adic input destroys the skew-product
  autonomy rather than merely perturbing it).

## 5. What this says about the whole approximator programme

Round 21 showed rational barriers change the pressure by `O(|α−p/q|)` and that the ShapeTail
certificate is already barrier-invariant.  This round adds: **no irrational surrogate of any
algebraic degree can help either**, because the difficulty is not in the barrier's arithmetic at
all.  The one genuinely new fact is positive and reframes the problem:

> The pressure system is a finite-dimensional (indeed one-dimensional) compact-fiber automaton
> **reading the ternary digits of `ξ`**.  Round 18b's "adversary" was exactly a choice of that input;
> the true environment is the specific input coming from `λ2^{−m}`.  Every open question in the
> programme is a question about that digit sequence.
